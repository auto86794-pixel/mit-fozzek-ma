# Varázsfazék V4 – 30 recept

A V3 továbbfejlesztése: 30 családi recept, 15 perces időszűrő, meglévő bevásárlólista, kamra és kedvencek.

A fotók pontos recepthez rendelése még nincs kész: a korábbi általános Unsplash-illusztrációk változatlanok. Ezeket külön ellenőrzött, ételspecifikus fotókkal kell lecserélni, mielőtt késznek tekintjük a fotós fejlesztést.

Teszt: `npm test`; build: `npm install` majd `npm run build`.


V4.1 fotók első szakasz: 9 recepthez külön AI-generált ételkép, a többi receptnél félrevezető általános fotó helyett ételikon jelenik meg. A teljes 30 fotós sorozat még nincs kész.
